## 技術 SEO 檢查

### 結構化標記
- [ ] 每頁只有一個 H1
- [ ] 每頁有獨立且符合內容的 title
- [ ] 每頁有獨立的 meta description（70-150 字）
- [ ] 標題不堆疊關鍵字
- [ ] 使用清楚的 H2 與 H3 層級
- [ ] 圖片提供 alt text（如有圖片）

### 頁面設定
- [ ] 頁面公開且未阻擋搜尋引擎
- [ ] Google Sites 設定中「允許搜尋引擎建立索引」已啟用
- [ ] 每頁的頁面路徑（URL）簡潔有意義
- [ ] 使用一致的內部連結（頁面之間互相連結）
- [ ] 提供更新日期與作者說明

### 內容品質
- [ ] 主要內容必須是可索引文字（不是圖片或 iframe 中的文字）
- [ ] 搜尋器（Web App）不應取代靜態內容頁
- [ ] 每頁內容直接回答患者問題
- [ ] 清楚呈現第一手經驗、資料來源與責任邊界

### 索引與收錄
- [ ] 已連接 Google Search Console
- [ ] 已提交 Sitemap
- [ ] 已要求建立索引（重要頁面）
- [ ] Search Console 中無嚴重錯誤

## 內容品質檢查

### 醫療內容安全
- [ ] 所有醫療內容使用準確措辭（「可能」「有些人」「值得評估」）
- [ ] 不以單一症狀確診疾病
- [ ] 不替使用者選擇治療
- [ ] 不提供藥物或營養品劑量
- [ ] 不保證恢復時間
- [ ] 不把情緒壓力當成疼痛是假的
- [ ] 不暗示檢查正常就代表沒有疼痛
- [ ] 不貶低任何醫療專業
- [ ] 緊急警訊醒目且獨立
- [ ] 每頁有醫療責任邊界說明

### 使用者體驗
- [ ] 第一次進入的人能在 30 秒內完成至少一件事：
  - 知道可能先看哪一科
  - 知道如何描述自己的疼痛
  - 找到一間可聯絡的院所
  - 知道什麼情況不能繼續等待

### 手機體驗
- [ ] 所有頁面在手機上可正常瀏覽
- [ ] 按鈕夠大（最小 44px 觸控目標）
- [ ] 文字不過小（最小 14px）
- [ ] 搜尋器在手機上可正常操作
- [ ] 症狀工具在手機上可正常填寫

## 重要提醒

> **網站排名不是因為使用 Google Sites 就會自動得到優待。**
> 內容要直接回答患者問題，並清楚呈現第一手經驗、資料來源與責任邊界。

> **搜尋器不應取代靜態內容頁。**
> 搜尋器是工具，但搜尋引擎能索引的主要是靜態文字內容。確保每個頁面都有充足的文字內容。
